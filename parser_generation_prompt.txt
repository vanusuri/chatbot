# MASTER ENGINEERING PROMPT
# LineageIQ — Enterprise Deterministic Parsing and Cross-Language Lineage Platform

## 1. ROLE AND OBJECTIVE

Act as a Principal Software Architect, Compiler Engineer, Python Engineering Lead, and Enterprise Data Lineage Specialist.

Design and implement a complete, modular, production-oriented Python application named **LineageIQ Deterministic Parser Engine**.

The platform must analyze enterprise application source-code repositories containing multiple programming languages, SQL files, configuration files, database access frameworks, and stored procedure references.

Its primary objective is to discover, extract, correlate, validate, and publish **system-level, application-level, table-level, column-level, transformation-level, and data-quality lineage** using deterministic techniques.

### Mandatory architectural constraints

1. Python 3.12+ must be the primary implementation language.
2. No LLM, generative AI, AI agent, prompt inference, or probabilistic code interpretation is permitted in the parsing and lineage extraction workflow.
3. Use language-aware AST parsers, compiler APIs, semantic analysis, symbolic evaluation, deterministic rules, and metadata-assisted resolution.
4. For C# and .NET, prefer Microsoft Roslyn via a separately deployable .NET parser adapter.
5. For SQL Server, prefer Microsoft ScriptDom through a .NET adapter.
6. For other SQL dialects, implement dedicated dialect-aware parsing adapters.
7. Python must orchestrate repository discovery, parser dispatching, intermediate representation, dependency resolution, lineage construction, canonical normalization, evidence validation, and graph publishing.
8. Never execute application source code to discover lineage.
9. Never fabricate unresolved dependencies or database objects.
10. Every published lineage relationship must contain traceable supporting evidence.
11. Keep parsing, semantic resolution, lineage derivation, and graph persistence as independent architectural components.
12. Support local execution, containerized execution, and eventual deployment to Google Cloud Platform.

Generate actual executable source code, not just architectural explanations or pseudocode.
